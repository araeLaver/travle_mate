## Description (260자 이내)
Fryndo matches solo travelers with compatible companions using AI. Create a verified profile, get matched based on travel style and personality, chat in real-time, and collect location-based NFTs as proof of your adventures. Join travel groups, share itineraries, and explore 50+ countries together.

## Competitors / Alternatives
- Tourlina — Women-only travel companion app
- Travel Buddy — Basic travel companion matching
- Couchsurfing — Accommodation-focused, not companion-focused
- Backpackr — Backpacker community

## Differentiation
- **AI 호환성 매칭** — 단순 프로필 목록이 아닌 성향 분석 기반 추천
- **Web3 NFT 통합** — 여행 경험의 게이미피케이션
- **그룹 여행** — 1:1뿐 아니라 3~10명 그룹 매칭 지원
- **글로벌 50+ 국가** — 다국어, 다문화 지원

---

## Technical Highlights (for Hacker News cross-post)
- Mobile: React Native (Expo) + TypeScript
- Backend: Spring Boot 3.4 (Java 17) + PostgreSQL
- Frontend: React 18 + Tailwind CSS + Framer Motion
- Real-time: WebSocket (STOMP) + Redis caching
- Blockchain: Solidity smart contracts on Polygon (NFT)
- Auth: JWT + Google OAuth + Apple Sign In
- Offline: Service Worker PWA + offline-first data loading
- Deployed on Koyeb with CI/CD
