## 1-1. 지메일 계정 15개 준비

**왜 15개인가**: 요건은 12명이지만 **연속 14일**이다. 13일째 한 명이 앱을 지우면
**시계가 0으로 리셋**된다. 3명은 이탈 버퍼다.

**만드는 방법** (크롬 시크릿창에서 반복):

1. https://accounts.google.com/signup 접속
2. 이름은 아무거나, 아이디는 `doori.test01` ~ `doori.test15` 식으로
3. **전화번호 인증을 요구하면 "건너뛰기"를 누른다.** 안 나오면 다음 항목 참고
4. 생년월일은 만 18세 이상으로

> ⚠️ **한 번호로 만들 수 있는 계정 수에 한도가 있다.** 보통 같은 기기/IP에서
> 3~5개쯤 만들면 전화번호 인증을 강제한다. 그때는:
> - 지인에게 부탁 (가장 빠름). "지메일 주소만 알려줘, 설치는 링크 하나 누르면 끝" 이라고 하면 된다
> - 네이버 카페 **"안드로이드 비공개 테스터"** 검색 → 상호 테스트 매칭 (무료, 며칠 걸림)
> - 크몽 "구글 플레이 비공개 테스트 테스터" 검색 (유료)
>
> **Fiverr 등 해외 초저가 대행은 쓰지 말 것.** 가짜 옵트인이 섞이면 계정 정지 사유다.
> 구글은 "테스터를 어떻게 구했는지"는 안 따지지만 "실제 사람인지"는 따진다.

**받아적을 것**: 15개 주소를 메모장에 한 줄에 하나씩. STEP 1-2에서 통째로 붙여넣는다.

# 부록 D — 개발자용 명령 모음

```bash
# 로컬 AAB 빌드 (EAS 무료 한도 소진 시)
cd travelmate-mobile
export JAVA_HOME=/opt/homebrew/opt/openjdk@17
npx eas-cli@23.2.0 build --platform android --profile production --local --output ./doorimate.aab

# 내부 테스트 트랙에 올리기
npx eas-cli@23.2.0 submit -p android --profile preview --path ./doorimate.aab --non-interactive

# 비공개 테스트(Alpha) 트랙에 올리기
npx eas-cli@23.2.0 submit -p android --profile closed --path ./doorimate.aab --non-interactive

# 웹 배포
cd travelmate-web
npx vercel@59.23.2 pull --yes --environment=production
npx vercel@59.23.2 build --yes --target production
npx vercel@59.23.2 deploy --prebuilt --prod --yes

# 백엔드 배포
cd travelmate-backend
koyeb deploy . fryndo/api

# 백엔드 깨우기 / 상태 확인
curl -s -o /dev/null -w "%{http_code} %{time_total}s\n" https://fryndo-untab-f93a6aa7.koyeb.app/api/health
```
