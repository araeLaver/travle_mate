## 3. 이번에 고친 것 — 안 고쳤으면 반려됐을 것들

### 계정 삭제가 가짜였다

`UserService.deleteUser()`가 `is_active = false`만 바꾸고 **아무것도 지우지 않았다.**
이메일·닉네임·자기소개·프로필 사진·전화번호·위치·FCM 토큰이 그대로 남아 있었다.
이 상태로 데이터 보안에 "삭제 요청 가능 = 예"를 선언하면 허위 선언이다.

고친 내용:
- 식별 가능한 컬럼 전부 제거, 이메일·닉네임은 플레이스홀더로 치환 (unique 제약 때문에 null 불가)
- 비밀번호를 난수로 덮어써 복구 불가
- 리프레시 토큰 전량 폐기 → 열려 있던 세션 즉시 종료
- `login()` / `refreshToken()`이 비활성 계정을 거부

행 자체는 남긴다. `group_members`·`chat_messages`·`user_reviews`가 `user_id`를 외래키로
잡고 있어 하드 삭제하면 **다른 사용자의 여행 기록이 깨진다.** Play가 요구하는 건 개인정보의
실제 제거이지 행의 물리적 삭제가 아니다.

**라이브 서버 검증 완료:**
```
계정 생성 → 로그인 → DELETE /api/users/account   → 204
같은 이메일로 재로그인                            → 404 "사용자를 찾을 수 없습니다"
```
백엔드 테스트 52개 통과.

### 계정 삭제 웹페이지가 없었다

데이터 보안 선언에 **공개 URL이 필수**다. 앱 이름, 앱 내 삭제 절차, 이메일 요청 경로,
지워지는 항목, 남는 항목과 보관 기간(신고 3년 / 접속 로그 90일)을 적어 만들고 배포했다.
→ `https://fryndo-web.vercel.app/account-deletion`

### 안 쓰는 권한이 선언 2건을 만들고 있었다

`ACCESS_BACKGROUND_LOCATION` · `FOREGROUND_SERVICE` · `FOREGROUND_SERVICE_LOCATION` ·
`RECORD_AUDIO` — 앱이 쓰지도 않는데 매니페스트에 있었다. 특히 백그라운드 위치는
**별도 영상 심사**까지 유발한다. 제거한 vc8을 올려 선언 2건이 사라졌다.

> EAS 무료 Android 빌드 한도가 이번 달 소진돼(10/1 리셋) **로컬로 빌드**했다. 비용 0원.
> 재현 방법: `JAVA_HOME=/opt/homebrew/opt/openjdk@17` 설정 후
> `eas build --platform android --profile production --local`
> (기본 JDK 25로는 Gradle이 "Unsupported class file major version 69"로 죽는다.)

### 심사용 계정에 아무 데이터가 없었다

로그인해도 그룹 0개, 매칭 추천 0명, 채팅 0개였다. 리뷰어 눈에는 빈 껍데기이고,
이건 "최소 기능 미달"로 반려되는 대표 사유다. 심사 계정과 데모 사용자·여행 그룹을 만들어 채웠다.

| 화면 | 이전 | 지금 |
|---|---|---|
| 동행 그룹 | 0개 | **5개** (경주·부산·속초·제주·전주) |
| 매칭 추천 | 0명 | **5명** (문화·먹방·자연·액티비티·휴양) |

심사 계정으로 실제 로그인해 위 숫자를 확인했다.

## 4. 출시 일정 — 왜 최소 14일인가

개인 개발자 계정은 프로덕션 액세스 신청 전에 **비공개 테스트 12명 이상 × 14일 이상**이
필요하다. **내부 테스트는 이 14일에 산입되지 않는다.**

```
오늘 ────────────────────────────────────────────────▶
  │
  ├─ 테스터 12명 등록 + 비공개 테스트 출시   ← 시계 시작
  │
  ├──────────── 14일 대기 ────────────┤
  │
  ├─ 프로덕션 액세스 신청
  │
  └─ 구글 심사 (보통 며칠) → 출시
```

**어떤 작업으로도 이 14일은 줄일 수 없다.** 그래서 ⑤-①을 오늘 시작해야 한다.
