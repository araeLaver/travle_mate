## 1. Executive Summary

**Fryndo**는 AI 기반 여행 동반자 매칭 + NFT 여행 기록 플랫폼입니다.
혼자 여행하는 사람들이 성향이 맞는 동반자를 찾고, 실시간으로 소통하며, 여행 경험을 NFT로 수집하는 소셜 플랫폼입니다.

- **한 줄 정의**: AI 호환성 매칭 + Web3 여행 기록 소셜 플랫폼
- **핵심 차별점**: 성향 분석 기반 매칭 + Polygon NFT 게이미피케이션
- **목표 시장**: 글로벌 솔로 여행자 (연간 2.5억+ 명)

## 3. 문제 (Problem)

### 솔로 여행자의 3가지 Pain Point

| # | 문제 | 상세 |
|---|------|------|
| 1 | **동행자 찾기 어려움** | SNS/포럼에서 여행 동행 구하기 → 시간 낭비, 검증 불가, 성향 불일치 |
| 2 | **안전 우려** | 낯선 사람과 여행 → 신원 미확인, 긴급 상황 대응 어려움 |
| 3 | **여행 기록 소실** | 사진/일기로만 기록 → 체계적 아카이빙 불가, 공유 한계 |

### 기존 솔루션의 한계
- **Couchsurfing**: 숙소 중심, 동행 매칭 아님
- **여행 카페/SNS**: 수동 매칭, 검증 없음, 사기 위험
- **Tourlina**: 여성 전용, 시장 제한
- **Travel Buddy**: 기본 프로필 목록, AI 매칭 없음

## 4. 솔루션 (Solution)

### Fryndo의 5대 핵심 기능

**1. AI 호환성 매칭**
- 여행 스타일 (30%) + 일정 겹침 (25%) + 예산 범위 (20%) + 언어 (15%) + 평점 (10%)
- 92% 이상 호환성 매칭 정확도 목표
- 매칭 알고리즘 지속 학습 (여행 후 평가 피드백)

**2. 실시간 소통**
- WebSocket 기반 1:1 / 그룹 채팅
- 위치 공유, 사진/파일 전송
- 여행 계획 공동 편집

**3. 신뢰/안전 시스템**
- 5단계 신뢰 배지 (Newcomer → Platinum)
- 신원인증 (이메일/전화/SNS/정부ID)
- 긴급 연락처 등록 + 신고 시스템

**4. 그룹 여행**
- 목적지별 3~10명 그룹 생성/참여
- 일정 공유, 비용 분담 기능
- 그룹 호환성 점수 표시

**5. NFT 여행 수집**
- Polygon 기반 위치 인증 NFT
- 5단계 희귀도 (Common → Legendary)
- 리더보드 + 포인트 시스템
- 추후 마켓플레이스 오픈 예정
