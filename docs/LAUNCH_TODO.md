# 출시까지 남은 일 — 당신이 해야 할 것

2026-09-20 기준.

**프로덕션 출시일 = 테스터 12명이 모인 날 + 14일.**
그러니 ①을 오늘 시작하는 게 제일 빠르다. 나머지는 30분이면 끝난다.

## ① 테스터 12명 — 이게 출시일을 결정한다. 지금 시작할 것

- 개인 개발자 계정은 프로덕션 액세스 신청 전에 **12명 이상 × 14일 이상 비공개 테스트**가 필요하다
- **내부 테스트는 이 14일에 산입되지 않는다**
- 필요한 건 **지메일 계정 12개**. 지인이든 본인 부계정이든 상관없다
- 넣는 곳: `테스트 및 출시 → 테스트 → 비공개 테스트 → 테스터`

②③을 아무리 빨리 끝내도 이게 없으면 시계가 안 돈다.

3-1이 끝나기 전에는 저장 버튼이 회색이다. 3-1을 먼저 할 것.

내용을 바꿀 필요는 없다. 참고로 이렇게 넣었다:

| 데이터 | 필수/선택 | 목적 |

| 기기 또는 기타 ID | 필수 | 앱 기능, 계정 관리 |
| 앱 상호작용 | 필수 | 앱 기능 |
| 기타 정보(나이·성별) | 선택 | 앱 기능 |
| 대략적인 위치, 정확한 위치 | 선택 | 앱 기능 |
| 기타 인앱 메시지 | 선택 | 앱 기능 |
| 사진 | 선택 | 앱 기능 |
| 기타 사용자 제작 콘텐츠 | 선택 | 앱 기능 |

- 제3자와 공유 → **아니요**
- 전송 중 암호화 → **예**

체크하고 다음을 누르면 설문지가 나온다. 답은 이렇다:

| 질문 | 답 |

| 사용자가 위치를 공유할 수 있음 | **예** (채팅 위치 전송) |
| 사용자 생성 콘텐츠 공유 | **예** (채팅·자기소개·프로필 사진) |
| 개인정보를 제3자와 공유 | **아니요** |
| 디지털 콘텐츠 구매 | **아니요** |

> 소통·위치 공유가 있으니 등급이 올라가는 게 정상이다. 숨기면 나중에 문제가 된다.

**콘텐츠 등급 이메일·카테고리 입력** (약관 체크만 ④에 남음)

**계정 삭제를 실제 삭제로 고침** — `deleteUser()`가 `is_active=false`만 바꾸고 아무것도 안 지우고 있었다.
그 상태로 "삭제 가능=예"를 선언하면 허위 선언이 된다. 이메일·닉네임·이름·나이·성별·자기소개·
프로필 사진·전화번호·위치·FCM 토큰을 전부 지우고, 비밀번호를 난수로 덮고, 리프레시 토큰을
폐기하도록 바꿨다. 로그인·토큰 갱신도 탈퇴 계정을 거부한다. 백엔드 테스트 52개 통과, Koyeb 배포 완료.

> 라이브 서버에서 실제로 확인했다: 계정 생성 → 로그인 → `DELETE /api/users/account` → **204**,
> 같은 이메일로 재로그인 → **404 "사용자를 찾을 수 없습니다"**. 이메일 자체가 지워져서
> 계정에 다시 닿을 수 없는 상태가 맞다.

**계정 삭제 안내 페이지 제작·배포** — `https://doorimate.co.kr/account-deletion`
데이터 보안 선언에 이 URL이 필수라서 만들었다. 앱 내 삭제 절차, 이메일 요청 경로,
지워지는 항목, 남는 항목과 보관 기간(신고 3년 / 접속 로그 90일)을 적었다.

**vc8 빌드 + 내부 트랙 업로드** — 안 쓰는 권한(백그라운드 위치·포그라운드 서비스·녹음)을
매니페스트에서 걷어낸 빌드다. 이게 올라가면 앱 콘텐츠의 **위치 정보 액세스 권한 / 포그라운드
서비스 권한 선언 2건이 목록에서 사라진다.**

> EAS 무료 Android 빌드 한도가 이번 달 소진돼서(10월 1일 리셋) **로컬로 빌드**했다. 비용 0원.
